# postcss-add-nesting

A [PostCSS](https://github.com/postcss/postcss) plugin that refactors declarations with related selectors to make use of [nesting](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Nesting).

## Tests

To run the tests, follow the steps below:

1. Clone the repository.

```bash
git clone https://github.com/VladNegara/postcss-add-nesting
cd postcss-add-nesting
```

2. Install the dependencies.

```bash
npm ci
```

3. Run the tests!

```bash
npx jest
```
